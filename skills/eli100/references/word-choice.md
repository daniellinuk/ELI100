# Word choice

Do not invent an official STE dictionary. This file has two lists: examples ASD has described in public, and fog words this skill always replaces. Anything else is a judgment, not an approval.

## Published examples

ASD's public description of STE says each approved word has one meaning and, in general, one part of speech. Spelling follows American English. These pairs are the examples those public pages use. In **full** mode, apply them. In **soften** mode, apply them when the simpler word keeps the meaning.

| Do not write | Write |
| --- | --- |
| begin, commence, initiate, originate | start |
| achieve, accomplish, carry out | do |
| acceptance | accept (verb) |
| accessible | get access to |
| close (adjective, "near") | near |
| fall, when you mean "decrease" | decrease, or a number |
| check, as a verb | do a check |

`about` means "concerned with". It does not mean "approximately". `approximately` and `around` are separate words in the public description. Do not swap them for `about`.

`close` as a verb, in the public summary, means to move something so material cannot go in or out, or to operate a circuit breaker. Do not use it for "close a meeting".

## Fog words

Replace these in both modes. Say the concrete action or the concrete thing.

| Word | Replace with |
| --- | --- |
| leverage, utilize | use |
| facilitate | help, or the action |
| optimize | the change you will make |
| robust | what still works when input is wrong |
| seamless | what the person does not have to do |
| empower | allow |
| holistic | whole |
| streamline | the step you remove |

Also replace `in order to` with `to`, `due to the fact that` with `because`, and `a large number of` with `many`.

## When the word is not in this file

1. Code, a quote, a label on a screen, or a product name: keep it.
2. A technical noun the project already uses: keep that exact name.
3. A long ordinary word with a shorter word that does not change the claim: use the shorter word.
4. Full mode, and you still are not sure: use the shorter word, or keep the technical noun. Say that you did not check the official dictionary. Never mark a word "approved" from memory.
